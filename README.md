# Pip-Ops

A .Net Core Help Desk Web App for large corporations with multiple branches and work areas

.Net Core + SQLServer

FEATURES

- Support tickets
- Working branch
- Working area
- Supervisors
- Support agents
- Normal users
- Agent's performance reports

This can be used as it is, but I plan to do it easier, and better.
